# Security policy

Burrow is a recovery product. Treat anything that could leak credentials, archive contents, or restore paths as a vulnerability — even while the first loop is not shipped.

## Supported versions

There is no released version yet. Report issues against `main`.

## Reporting a vulnerability

**Do not file a public GitHub issue.**

Use GitHub's private advisory form:

https://github.com/omkar273/burrow/security/advisories/new

Include enough to reproduce: what you did, what you expected, what happened, and whether any data or tokens were exposed.

There is no `security@` address yet. When one is published, this file will list it. Until then, private advisories are the contact.

We will acknowledge the report, keep the conversation private until a fix is ready (or until we agree it is not a vulnerability), and credit you if you want that.
